# 桌面 0.3.29：修复无限制额度响应被客户端拒绝

0.3.28 服务器已支持个人及团队的 5 小时、7 天上限留空即无限制，但桌面端仍保留“可用状态必须有 7 天上限”的旧校验。登录成功后，合法额度响应因此被误判为“服务返回的数据格式不完整”，额度页无法显示。

本次仅移除该旧前提，保留额度耗尽、字段缺失、数值范围和成员数据一致性校验。未设置上限的窗口按无限制显示，明确设置为 `0` 或已耗尽的额度仍不能被标记为可用。

新增通过实际 Axios API 方法和响应校验的回归测试，覆盖团队周上限为空而个人周上限已设置、所有窗口未设限、无团队且个人未设限，以及额度用尽时仍拒绝矛盾的可用状态。

本次只更新桌面客户端。中央服务器继续使用 **0.3.28**，独立统计服务继续使用 **0.2.7**。已有服务器地址、额度配置和用量记录无需更改。

关闭旧客户端后安装 **0.3.29**，重新打开额度总览。安装包仍包含离线 WebView2 运行时，不含 Java 或本地业务后端。
