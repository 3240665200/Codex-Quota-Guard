# v0.3.5

本版本修复 Windows 安装包漏检旧版的问题，应用名称、应用 ID 和当前用户安装方式不变。

- 当前用户旧版沿用原目录升级；机器范围旧版显示版本及路径，经确认和正常 UAC 授权后迁移。
- 迁移保留用户数据和独立统计服务；取消、卸载失败或旧版残留会阻止后续安装。
- 避免将共享注册表视图误认为两份安装；损坏记录、多份安装和历史 MSI 冲突明确提示处理。
- 固定 Tauri CLI 2.11.5 与安装模板版本，新增兼容策略和完整模板编译回归测试。

Windows x64 安装包继续包含 Java 17 运行时、WebView2 离线安装器及 Rust 统计程序 0.2.2，不要求目标电脑安装开发环境。

自动化验证不执行真实安装、卸载或 UAC。实际旧版迁移及数据保留仍需在目标电脑进行安装验收。
