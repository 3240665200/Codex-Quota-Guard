# 桌面 0.4.1：恢复中断的覆盖升级

0.4.0 安装器先替换桌面文件，再安装必需的统计服务。服务安装失败或安装中断时，目录中可能已是新主程序，而卸载程序及 Windows 安装记录仍保留旧版本。原校验要求三者版本完全一致，导致再次运行安装包时提示“旧版本程序文件缺失或产品版本不匹配，不能自动升级”。

本版本允许经过文件指纹验证的当前用户安装从这种中间状态恢复，仍要求原目录、产品身份及旧卸载记录有效。未知文件、被改动的文件、跨用户安装、机器范围冲突及降级仍会被拒绝。安装器不通过改写旧版本号绕过检测，也不运行版本不匹配的旧卸载程序。

修复规则同时验证新安装包自身主程序的 SHA-256，支持同一安装包失败后的再次运行。对已有的 0.4.0 中断状态，仅认可已核验的 NSIS 主程序指纹 `90c3a0cd9e1802b9d23c49c2a6a09220d2a406a175618196cb50c22d971f5acb`。该文件与验证过的 0.4.0 构建完全一致，仅有 Tauri 在打包时将 `__TAURI_BUNDLE_TYPE_VAR_UNK` 标记改为 `NSS` 的三个字节差异。

## 使用方式

关闭报错的旧安装器，运行项目内 `dist/desktop-v0.4.1/Codex Quota Guard_0.4.1_x64-setup.exe`，继续使用原安装目录。当前机器原目录为 `D:\Codex Quota Guard`。按 Windows 提示授权安装统计服务，安装器会检查服务启动结果，再登记安装成功。

本次只修复桌面安装流程，USD 计费功能及独立统计服务 0.2.8 保持不变。后台继续配套 0.4.0，配置、设备身份和统计队列保留；USD 设置与本机后台启动方式见 [0.4.0 说明](./v0.4.0.md)。
