# 服务器 0.3.25

服务器后端与管理网页统一升级至 `0.3.25`，与桌面 `v0.3.25` 配套使用。

| 组件 | 固定镜像标签 |
| --- | --- |
| 中央后台 | `minjm/codex-quota-guard-backend:0.3.25` |
| 管理网页 | `minjm/codex-quota-guard-web:0.3.25` |
| 数据库 | 保留原有 `postgres:17-alpine` 与数据卷 |

本次增加官方额度定时轮询、失败退避与授权变化隔离；支持 Google Authenticator 兼容的 TOTP 登录辅助；提供当前团队全部成员的用量明细及个人剩余额度/团队用量占比；管理端用户额度增加进度条，两端设置支持“剩余 / 已用”。官方百分比与系统 Token 计量分别展示。

升级会执行 V35、V36 两项新增表迁移。保留原数据库、JWT、邮箱、官方授权和代理加密密钥；升级前备份数据库、`.env` 和 Compose 配置。旧镜像用于故障排查及回滚准备，回滚前仍须评估迁移与数据兼容性，不自动恢复数据库或覆盖后续数据。

镜像平台为 `linux/amd64`，后台保持非 root 运行，包含 sing-box 1.13.14，不包含 Chromium。此次分发使用已经校验的 `backend-v0.3.25` JAR 和生产网页构建镜像，复用 0.3.23 的运行环境；源码多阶段 Dockerfile 同样保留，可在基础镜像仓库可用时重新构建。镜像与公开分发包不得包含真实配置、私钥或数据库备份。

部署检查包括容器健康、V35/V36 迁移、认证入口、网页资源哈希和镜像版本。真实官方账户联调、真实 Gmail 收码和 Windows 安装/开机恢复属于另外的目标环境验收，不将模拟测试计入这些验收。
