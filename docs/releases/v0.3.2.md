# Codex Quota Guard v0.3.2

Windows x64 桌面客户端，包含此前仅本地打包的 v0.3.1 窗口与界面改进，以及本次 CC Switch 强制终止通知。

## 本版更新

- 强制结束 CC Switch 后，由桌面 Rust 线程弹出需要确认的 Windows 原生警告框；隐藏到托盘时也能提醒，不再只依赖页面的短暂提示。
- 统计程序保留当前 lease 的终止事件累计记录；状态回到 `CLEAR` 后仍可通知。同一事件去重，连续终止可合并显示进程数量，显示失败保留重试。
- 统计程序升级到 **0.2.2**，支持同 lease 服务重启恢复记录、部分成功后报错仍保留终止数量，以及旧格式记录兼容。
- 默认窗口调整为 960×640，并按屏幕工作区及 DPI 适配；记住用户手动调整的正常窗口尺寸，下次启动恢复。
- 侧栏和登录页使用软件原有图标；隐藏主内容、日志、流水及详情弹窗的滚动条外观，保留滚轮、触控板和键盘滚动。
- 统一额度卡片的数字基线、标题和进度条对齐，Token 单位使用独立小字号，并优化小窗口布局。

## 安装与升级

1. 下载附件 `Codex.Quota.Guard_0.3.2_x64-setup.exe`。
2. 从系统托盘退出旧版 Quota Guard，再安装新版。
3. 以管理员身份运行安装后的客户端，让启动检查更新随包统计程序；在“统计程序”页面确认运行版本为 **0.2.2**。

安装包内含 Java 17、WebView2 离线安装程序和 Rust 统计程序，用户电脑不需要开发环境。中央 Java 服务和管理后台需单独运行，本次不涉及数据库迁移。安装包未进行代码签名，Windows 可能显示未知发布者提示。

## 使用边界

- CC Switch 强制结束的匹配范围保持不变：同一 Windows 用户、同一会话，并通过既有进程身份核验。未保存修改可能丢失，终止进程不会自动恢复 Codex 官方直连配置。
- 关闭到托盘不等于退出；要继续使用 CC Switch，请先从托盘退出 Quota Guard。
- 必须同时更新桌面端与统计程序，旧统计程序的兼容提醒只能尽力捕获。锁屏、安全桌面、客户端退出/崩溃或状态文件无法写入等情况不保证即时交付。
- 官方额度、系统 Token 限额和 USD 费用估算仍是不同口径；守卫不能防止拥有本机管理员权限的人绕过，也不能替代官方账户 ID 归属校验。

## 验证说明

本版执行前端、桌面 Rust、统计程序、Java 后端自动化测试及打包资源校验。需要真实 Windows 服务或官方在线环境的测试保留跳过；没有通过结束真实 CC Switch 来验收通知可见性，也没有在全新电脑执行安装测试。仓库当前未配置 GitHub Actions CI。预览演示数据不包含在生产安装包中。

附件 `SHA256SUMS.txt` 提供安装包校验值。
