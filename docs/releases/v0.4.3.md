# v0.4.3：USD 计费与速度模式识别

Windows x64 桌面客户端 0.4.3，内置独立 Rust 统计服务 **0.2.10**。配套后台为本次源码中的 **0.4.2**；旧 Token 后台需要同步升级。

## 本次发布

- 个人、团队及官方账户额度按模型价格表核算 USD，保留 Token 分项和账本单价快照；普通与快速模式分别使用配置倍率，快速模式默认 1.5。
- 从 Codex 本机诊断信息按真实逻辑会话、轮次及事件时间匹配速度模式。修复会话续接后 rollout 文件 UUID 改变、导致速度模式一直待确认的问题。
- 为近期已上传但尚未核算的记录补报可确认的速度模式，不修改已核算金额，也不重建已经删除的记录。
- 修复安装中断后覆盖升级被版本校验阻挡的问题；统计服务随安装包强制安装，使用 Windows 自动启动和故障恢复，桌面完全退出后仍可采集与上报。
- 同步后台 USD 核算、计费模式确认及每分钟失效会话绑定清理代码。未设置的额度上限仍为无限制。
- Windows 打包的编译、工具及临时缓存默认使用 D 盘，安装包输出与缓存分开存放。桌面不包含 Java 或本地业务后端。

## 升级与核对

运行安装包并覆盖原安装目录，按 Windows 提示授权更新统计服务；安装完成后，在“统计程序”页面核对运行版本为 **0.2.10**。服务约每分钟尝试补报近期缺失的速度模式，原始日志必须仍然存在且可读取。

团队成员各自的设备均需使用新版统计服务。其他成员缺失的速度模式不会由当前管理员设备猜测补齐。未知模式、模型或 Token 分项仍会待核算。

超过接收时间范围或时间超前的旧记录仍保留在本机，本版本尚无后台异常用量审核入口。

后台升级包含 V38–V40 增量迁移，保留账户、记录及旧 Token 配置。新的 USD 上限需要管理员配置，留空表示无限制；不要将旧 Token 数字直接当作美元上限。

- 桌面打包：14 项测试通过；正式前端资源、WebView 渲染及中央 HTTP 访问探针通过。
