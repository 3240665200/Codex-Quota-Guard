# 0.3.14 本地测试版

## 本次变化

- 后台“官方账户 → 授权与会话”新增“登出所有会话”和“登出所有未绑定会话”。后者排除已绑定、受信任、信任状态未知以及当前管理会话；两项操作均先预览再确认。
- 桌面登录后先验证当前用户和本设备的官方会话绑定。未绑定或校验失败时仅开放“登录辅助”，其他菜单禁用；本机 Java 与中央后台均执行检查。
- 管理员官方登录助手可以从“登录辅助”进入，未绑定设备也能先完成官方授权。
- Rust 统计程序升级为 0.2.3：桌面完全退出后仍独立运行；新增持久待传队列、自主授权续期、错误记录隔离与归属核验。

## 安装与测试

1. 先更新配套中央后台与管理网页，保留数据库和原加密密钥。新后台自动应用 V26；旧桌面客户端缺少新的设备绑定请求头，需要配套升级。
2. 从系统托盘退出旧桌面客户端，再覆盖安装 0.3.14。以管理员权限启动后，检查“统计程序”中的运行版本为 0.2.3。
3. 本机预览管理地址为 `http://localhost:8000`；桌面服务器地址填写 `http://127.0.0.1:18080`。这里的地址仅用于本机测试，不是远程服务器部署地址。
4. 无绑定用户应只能使用“登录辅助”。完成队列登录、唯一会话识别与确认，后台验证通过后才开放其他菜单。断网或绑定撤销后应重新锁定。
5. 完成配对后，从托盘完全退出桌面，在官方 Codex 产生新用量；通过管理后台核对设备心跳和逐笔流水。关闭桌面窗口进入托盘不算完全退出。
6. 测试官方登出前核对预览：全部登出可能影响你正在使用的官方账号与管理授权。结果不确定时需要到官网核对，系统不会自动重发。

## 边界

- 本轮未对真实官方账号执行登出，也未停止用户正在运行的统计服务。退出桌面、断网重启与日志删除补传由独立测试进程和模拟后台验证，真实设备仍需上述验收。
- 统计仅覆盖服务能读取的受支持 Codex 日志；管理员停用服务、修改日志或官方未写出的记录无法保证采集。
- 超过后台 30 天接收窗口、归属不明或被拒绝的记录会保留并报告，不篡改时间、不计给其他用户。设备授权被撤销、用户禁用或超出离线续期宽限时不会自动恢复。
- 设备 UUID 是安装标识，不是不可克隆的硬件身份。官方接口是网站内部接口，真实连接仍可能需要重新登录或受官方访问限制。
- 这是本地测试包，尚未发布 GitHub Release 或更新 Docker 镜像。
