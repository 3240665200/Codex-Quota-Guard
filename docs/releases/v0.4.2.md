# 0.4.2：自动识别速度模式，清理失效会话绑定

桌面安装包包含独立统计服务 0.2.9。服务按 Codex 本机诊断记录中的会话、轮次和时间匹配 `service_tier`，识别普通模式与快速模式，再随用量上报。快速模式按后台价格表中的倍率计算，默认 1.5；这属于本系统计费配置。不会用当前全局配置推断历史用量。

统计服务不依赖桌面窗口。完成安装、登录和设备配对后，退出桌面客户端仍持续采集和上报。服务每分钟尝试补全近期已上传、尚未核算记录的速度模式；只修改该用户及设备的现有待核算记录，不重建已删除的账单，也不修改已核算金额。诊断记录缺失、格式无法识别、价格或 Token 分项缺失时仍显示待核算。

后台“限制管理”新增“失效会话绑定清理”，默认启用，检查间隔 1 分钟。只有官方会话列表成功刷新、身份一致、列表完整时，才结束已经消失的旧会话绑定，同时关闭其旧登录绑定流程。已存在的官方会话和查询期间新建的绑定保留。查询失败或限流时保留绑定，限流进入冷却期。本任务只解除本地绑定，不向官方发送下线请求。

数据库使用 V40 增量迁移，保留账户、额度设置、绑定历史和用量记录。桌面继续使用原安装目录覆盖升级；安装由用户自行执行。
