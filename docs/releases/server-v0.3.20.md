# 服务器 0.3.20：统一授权流程与离线镜像

验证及发布日期：2026-10-16。平台：Linux amd64。源码与配套配置发布于 `server-v0.3.20` 标签；后端和网页的 `0.3.20` 与 `latest` 均已发布到 Docker Hub，摘要与已验证的本地镜像一致。公开镜像不含个人授权文件。

## 行为一致

- 发布、开发和测试使用同一套业务实现。HTTP/HTTPS 传输默认统一，仍可显式启用 HTTPS-only；文件导入不再只向 localhost 开放。
- 官方授权页支持后台私有预置一键应用，以及 txt/JSON 文件导入草稿后明确保存。后台预置通过 `OFFICIAL_AUTHORIZATION_PRESET_FILE` 配置，镜像与源码不包含个人 Authorization/Cookie。
- 默认镜像不再安装 Chromium，不再构建浏览器专用版本。打开官方登录会在用户自己的浏览器新标签页打开 `https://chatgpt.com/`，不会自动抓取跨站 Cookie，也不会伪造 OAuth 授权完成。
- 预置授权只应用到管理员选中的官方账户登记，保留代理选择、版本冲突检查和已验证账户身份保护；保存后须刷新官方账户与会话才能确认连接状态。
- HTTP 和 HTTPS-only 使用同一个健康探针：本地认证入口返回 401 或预期的 302 才健康；网络失败或其他状态不算成功。

## 升级

0.3.19 → 0.3.20 无新增数据库迁移，桌面版本保持 0.3.18。备份后在原部署中同时更新后端/网页，保留原数据库卷、项目名、`.env` 和加密密钥。移除旧 browser overlay 参数，不删除原卷或重新初始化。

私有离线包包含镜像、部署配置及用户自己的 `secrets/official-authorization.json`，只能私下传给该用户的服务器，不得公开分发。导入镜像后用 `--pull never --no-build` 启动；后台非 root UID 10001 需要对该预置文件拥有读取权限。详见[统一部署说明](../../deploy/docker/registry/README.md)。
