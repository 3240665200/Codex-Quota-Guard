# 0.3.25：独立统计服务、团队用量与官方账户额度

> 桌面端的连接安全策略问题已在 [0.3.27](https://github.com/3240665200/Codex-Quota-Guard/releases/tag/v0.3.27) 修复，请使用新版桌面。中央后台 0.3.25 与新版桌面兼容。

- 桌面端通过 Axios 直连中央后台，不再捆绑 Java、本地 HTTP 后端或客户端保活服务。
- 安装器必须安装独立 Rust 统计服务 0.2.6，并配置 Windows 自动启动与故障恢复。
- 后台按配置的时间间隔读取官方账户额度，支持冷却、限流退避与授权变化隔离。
- 登录辅助支持加密保存的标准 TOTP 密钥和 Google Authenticator 兼容验证码。
- 用户额度列表增加实际用量进度条；两端设置支持“剩余 / 已用”显示偏好。

安装包位于 `dist/desktop-v0.3.25`。后台 JAR 与生产网页位于 `dist/backend-v0.3.25`，ZIP 为 `dist/backend-v0.3.25.zip`。后台包依赖当前项目已安装的 Node 依赖、Java 17 和原有受保护配置，不包含数据库或凭据。

根目录的 `一键启动-已打包管理后台.cmd` 运行打包后的 JAR 与生产网页，不会在启动时重新执行测试。它仅在本机监听，成功后打印对应的停止命令。

Windows x64 安装包内含独立统计服务 0.2.6 和 WebView2 离线安装器，因此约 212 MiB；不包含 Java 或本地 HTTP 后端。安装统计服务需要 Windows 管理员授权。安装器及本机后台已完成打包和资源验证，真实管理员安装及开机恢复仍需在目标电脑验收。

服务器后端与网页镜像统一使用 `0.3.25`，保留 sing-box 1.13.14。升级新增 V35 官方额度轮询状态表和 V36 验证器密钥表；更新前备份数据库及部署配置，并保留既有加密密钥和数据库卷。桌面发行标签为 `v0.3.25`，服务器源码标签为 `server-v0.3.25`。

已完成桌面前端 255 项、相关后台 131 项和额度后台补充 6 项测试，以及两端类型检查、生产构建和桌面资源/WebView 验证。管理网页上一轮 439 项中有 1 项旧路由断言，修正后定向复测通过。Edge 官方接口实机抓包与真实 Gmail 收码的未完成验收仍按已有说明保留；不将模拟接口测试描述成真实账户验收。
