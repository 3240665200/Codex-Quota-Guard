# v0.3.7

修复普通双击启动时没有请求 UAC、只显示管理员权限门禁的问题。

- 普通启动与登录自启动在权限不足时共用正常 Windows UAC 提权流程。
- 已以管理员权限启动时不重复提权；取消授权则退出原启动器，不进入客户端。
- 保留当前 Windows 用户身份校验、固定启动路径和参数，以及防止循环提权的检查。
- 不改写系统 UAC 策略、兼容性设置或已有自启动开关。

请从托盘退出旧客户端后覆盖升级。不要给 EXE 永久勾选兼容性“以管理员身份运行”：该标记会导致普通权限登录任务在进入程序前被 Windows 拒绝（`0x800702E4`）。

现场已调用原有登录启动入口，用户确认 UAC 显示并点击“是”。这证明该入口可请求权限，不代表重新登录或重启后的任务触发已经验收。
