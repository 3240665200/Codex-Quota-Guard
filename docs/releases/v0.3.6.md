# v0.3.6

本版本将开机自启动检测及错误提示的修复纳入 Windows 安装包。

- 兼容 Windows 返回的账户名，通过解析后的 SID 严格确认用户身份。
- 同时识别原始任务标记与 Windows 返回的精确任务路径，不放松程序路径、参数、触发器和权限校验。
- 保留自启动的实际开关；不因启动程序而重新启用已关闭的任务。
- 区分任务身份不匹配与任务计划程序读取失败，前端和启动提示保留明确的安全错误信息。
- 继续包含 0.3.5 的旧版安装识别与迁移兼容修复。

升级前请从托盘退出旧客户端。当前用户版本沿用原目录安装；所有用户版本按安装器提示迁移到当前用户可写目录。完成后以当前 Windows 用户的管理员身份运行新版。0.3.5 安装包没有本次自启动修复。

已对现有任务完成只读识别验证，未改动真实任务或开关。真实开关写入、UAC 和重新登录后的自动启动，仍需在目标电脑验收。
