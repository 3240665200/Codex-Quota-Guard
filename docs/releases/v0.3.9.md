# v0.3.9 — 邮箱登录辅助

- 桌面新增「登录辅助」：点击监听、等待就绪后发送登录邮件，只取新到的第一封匹配验证码，收到即停止，可重复、取消和超时。
- 管理员在「官方账户 → 邮箱配置」维护邮箱。提供 14 类常用服务商预设及自定义 IMAPS，支持应用密码及 Google/Microsoft OAuth2 Refresh Token 配置。
- 中央 Java 服务负责监听；用户只能使用所属团队绑定账户。同账户排他监听，邮箱授权加密保存，验证码短时展示，客户端不持有邮箱授权。
- 保留 Windows 普通启动项、独立 Rust 统计服务、用户与团队额度功能。

## 更新方式

需要同时更新中央 Java 后端、管理网页和桌面客户端。后端 Flyway V21 新增两张表，不修改已有用户及额度数据。管理员必须配置独立邮箱加密密钥和邮箱授权；未配置不会影响其他模块。

从托盘退出旧桌面端后覆盖安装。管理员保存邮箱配置并测试连接，将用户分配到关联团队。用户等待「正在监听」再到官方页面发码。

默认监听 180 秒，收到码最多展示 60 秒；同账户同一时刻只有一名监听者。OAuth 目前由管理员录入已授权的 Client ID/Secret/Refresh Token，不包含站内一键授权流程。预设并非真实邮箱全部联机验收，套餐、区域、IMAP 开关和服务商限制仍需确认。

配置说明及安全边界见[邮箱登录辅助](../architecture/login-assistance.md)。本次没有使用真实邮箱测试取码，也不保证邮件能与具体设备登录请求一一绑定。
