# Codex Quota Guard v0.3.1

## 本版更新

- 默认窗口调整为 960×640，按屏幕可用区域和 DPI 自动适配。
- 记住用户手动调整后的正常窗口尺寸，下次启动恢复；不把最小化、最大化或全屏的临时尺寸保存为正常窗口大小。
- 使用软件原有图标替换侧栏及登录页的品牌占位图标。
- 隐藏主内容、统计日志、流水表格和详情弹窗的滚动条，保留滚轮、触控板和键盘滚动。
- 对齐不限额/有限额卡片的数值基线、团队与官方额度的标题和进度条，缩小 Token 单位字号。
- 优化小窗口的卡片换列、图标侧栏、登录页、流水和详情弹窗布局。

## 安装说明

- Windows x64 安装包包含 Java 17、WebView2 离线安装程序和 Rust 统计程序 0.2.1；用户电脑无需安装开发环境。
- 先从托盘退出旧客户端，再安装新版。每次运行安装后的客户端仍需管理员权限。
- 中央 Java 服务和管理后台需单独运行；本次没有修改数据库结构或统计采集口径。
- Windows CC Switch 冲突守卫保持原有行为：客户端运行期间会强制结束当前 Windows 用户会话中识别到的 CC Switch，未保存更改可能丢失。
- 安装包未进行代码签名；Windows 可能显示未知发布者提示。

本版按本地自动化测试与构建资源检查验证；没有在全新电脑执行安装或启动真实统计服务。界面预览的演示数据不包含在生产安装包中。
