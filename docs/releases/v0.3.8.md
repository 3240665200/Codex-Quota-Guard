# v0.3.8 — Windows 普通启动项

- 桌面自启动改用当前用户的普通启动项，可在任务管理器「启动应用」中查找 Codex Quota Guard 并启用、禁用。
- 客户端设置页在打开、返回窗口或恢复可见时读取 Windows 实际状态，保存后再次核验，不擅自重开外部禁用项。
- 首次管理员启动时迁移本安装的旧计划任务，保留原开关，并在验证后移除旧任务，避免重复启动。
- 保留自选安装目录、正常 UAC 授权与独立的 Rust 统计服务。关闭桌面自启不会关闭统计服务。
- 未识别的启动状态、记录归属不匹配或迁移失败会明确提示，不覆盖未知记录。

## 升级与验收

从系统托盘退出旧客户端，覆盖安装到原目录，再启动一次并确认 UAC，完成迁移。任务管理器如仍显示旧列表，请关闭后重新打开。在其中禁用、启用后返回客户端设置页，检查开关一致。最后注销并重新登录 Windows，确认启动入口与 UAC；此次是登录启动，不承诺开机后立即执行。

主 EXE 不要永久勾选兼容性选项「以管理员身份运行」；应用自身会在需要时请求授权。取消 UAC 不启动桌面客户端，已经运行的统计服务保持独立。

自动化验证不运行安装器、不写入真实启动项、不执行真实迁移。真实任务管理器联动及登录启动需按上面的步骤在目标电脑验收。

已通过：前端 124 项测试、Rust 全量 142 项测试、安装器 14 项测试、打包规则 8 项测试，以及类型、格式与 Rust 严格检查。另单独运行只读探针，正确识别本机 0.3.7 的旧任务与实际启用状态；需要真实服务操作的测试未执行。本机未配置覆盖率工具，未宣称覆盖率达标。
