# 0.3.15 本地测试版

## 本次变化

- 取消或失败的绑定任务，在没有隔离保护时提供明确的重新申请入口；旧错误不再永久隐藏重试操作。
- 已取得登录名额后取消的任务，明确提示等待管理员核对并恢复队列。检查状态不会自动解除隔离，恢复后仍需用户手动重新申请。
- 登录辅助显示经过分类的邮箱连接错误，帮助区分地址解析、认证、TLS、超时和文件夹等问题；不显示原始邮箱服务响应或凭据。

## 配套要求

- 邮箱监听的具体错误分类需要同步更新中央后台。桌面安装包不包含中央后台和管理网页。
- 本次保持 Rust 统计程序为 **0.2.3**；Windows 安装范围、安装方式和自启动行为沿用 0.3.14。
- 不会自动解除现有绑定隔离，不会为重试而重置旧登录基线，也不会自动操作官方会话。

## 手工验收

1. 从系统托盘退出旧桌面客户端后，在测试机覆盖安装；沿用原中央服务地址和已有配置。
2. 未取得登录名额时取消任务，确认可以明确重新申请；已经取得名额后取消，确认仍需管理员恢复。
3. 管理员完成核对并恢复队列后，重新读取状态，再手动申请绑定。
4. 邮箱连接失败时检查分类提示；真实邮箱连接和官方登录由用户自行验收。

这是本地测试包，不发布 GitHub Release，也不更新 Docker 镜像。构建验证不代表已在用户设备执行安装或真实邮箱、官方会话操作。
