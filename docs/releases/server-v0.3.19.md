## HTTP 与 HTTPS

- 官方授权、服务器网页登录、会话管理、代理节点和设备绑定统一遵循 `app.require-https`，不再额外强制 HTTPS。
- 基础 Compose 的 `APP_REQUIRE_HTTPS=false` 允许 HTTP 和 HTTPS。管理页在 HTTP 下提示明文风险，不再仅因远程 HTTP 禁用功能。
- 可选 HTTPS overlay 仍设置 `APP_REQUIRE_HTTPS=true`，并将 HTTP 重定向到 HTTPS；这是主动选择的部署策略。
- 管理员权限、用户与设备归属校验、授权加密保存、敏感响应 `no-store`、官方站点 TLS 校验与浏览器沙箱保持不变。HTTP 并非加密连接，密码、令牌及浏览器输入可能被窃听或篡改。

服务器网页登录在两种协议下都需要 `minjm/codex-quota-guard-backend:0.3.19-browser` 和配套浏览器 overlay、seccomp、资源限制。HTTP 模式不需要域名或证书，也不要加入强制 HTTPS 的 overlay。管理员仍须本人完成官方登录和验证；此次修复不保证第三方站点接受所有服务器网络。

## 升级

从 0.3.18 升级没有新增数据库迁移，仍为 V30。备份后同步更新后端和网页镜像，保留 `.env`、数据库卷、项目名和全部密钥，不重新初始化，不删除数据卷。普通镜像使用 `0.3.19`；浏览器后端使用 `0.3.19-browser`。旧 0.3.18 标签不覆盖。

详见[升级步骤及 HTTP 浏览器启动命令](../../deploy/docker/registry/README.md#从-0318-升级)。本次不新增 Windows 安装包 Release；已有 0.3.18 桌面客户端无需为这项服务器修复重新安装。
