# 0.4.0：USD 额度与快速模式计费

桌面安装器已有 [0.4.1 修复版](./v0.4.1.md)，修复服务安装失败后再次运行被旧版本校验阻挡的问题；桌面安装请使用项目 `dist/desktop-v0.4.1` 中的安装包。后台及本文的 USD 计费方案不变。

个人、团队和官方账户的额度以 USD 统计。Token 保留为用量分项和审计数据，后台依模型价格表计算每笔金额。每笔入账保存单价与倍率快照，之后调价不修改旧账。普通输入会扣除缓存读写部分；思考 Token 已包含在输出中，不重复计费。

桌面版本为 **0.4.0**，独立 Rust 统计程序为 **0.2.8**。桌面仍通过 JS Axios 请求中央 API；安装包不包含 Java 或本地业务后端。Windows 服务独立采集与上报，桌面完全退出后仍运行，服务自启动及故障恢复沿用 Windows 服务机制。

## 历史迁移与额度设置

升级会执行 V38、V39：新增美元上限和账本，按升级当时的价格表回算历史用量，并标明“历史回算”。旧 Token 配置保留用于审计，新 USD 上限不会按 Token 数字自动转换。

**升级后需要重新配置个人、团队和官方账户的 USD 上限。留空表示无限制，明确填写 0 表示额度用尽。** 关联官方账户的团队累计上限取该账户的美元预算；官方账户总消耗按其关联团队归集，团队换绑不会改变已入账记录的账户归属。旧历史记录的账户归属采用升级时的团队关联。

1. 在“用量统计 → 模型定价”确认实际模型名称、每百万 Token 的输入／输出／缓存单价。免费项明确填 0。
2. 在“官方账户”设置账户 USD 预算，在“团队与额度策略”设置团队 5 小时、7 天上限，在“用户管理”设置个人上限。
3. “限制管理 → 个人额度限制”可以设置 **1～1440 分钟**的检查间隔。只有已确认费用达到个人上限时，才触发原有绑定会话下线流程；费用待核算本身不会触发自动下线。
4. 缺少价格的记录保持待核算，补齐价格后点击“核算待定价记录”。缺少分项或速度模式的记录不会伪装成零费用。已用金额仅为已入账小计，存在待核算记录时会明确提示。

官方接口返回的套餐百分比仍单独显示为“官方套餐参考”，不会据此虚构美元余额。这些 USD 额度是本系统预算和核算账本，并非 OpenAI 的实际美元账单。

## 快速模式

`fast`／`priority` 默认按 **1.5 倍**计费，每个模型的倍率可以在价格表编辑。`standard`／`default` 按普通费率。不会用模型名称或思考强度猜测速度模式。

**当前已检查的 Codex 会话日志并未提供速度模式字段，因此不能自动确认所有请求是否开启快速模式。** 新用量缺少明确模式时默认待核算。管理员可以使用以下入口：

- “额度查看 → 查看用户额度 → 设备计费模式”：设置该设备从保存时间起采用的普通／快速计费声明。切换 Codex 快速模式时要同步此设置；它不会替你切换 Codex，也不是官方验证。设置保存在服务器，客户端退出后仍生效。
- 同页“Token 用量流水”：选择尚未入账、模式未记录的记录，点击“按普通模式确认”或“按快速模式确认”。确认会保存操作者、模式依据及价格快照；已入账流水不能通过此入口重算。

设备声明按事件发生时间匹配，而不是上报时间。旧离线事件不会套用后来设置的模式。历史回算中未记录模式的记录采用普通费率并明确标记，这与历史迁移方案一致。

核算示例：非缓存输入单价 $2/M、输出 $10/M、缓存读 $0.2/M、缓存写 $3/M；输入 1,000,000（含缓存读 200,000、缓存写 100,000）、输出 500,000（含思考 200,000）时，普通费用为 **$6.74**，默认快速模式为 **$10.11**。

## 本机启动测试

已打包的本机后台位于项目 `dist/backend-v0.4.0`，包含中央 API JAR、管理网页和校验清单。使用项目现有的 Java 17、Node.js 和受保护的本机配置：

```powershell
Set-Location E:\project\pingche
powershell -NoProfile -ExecutionPolicy Bypass -File .\dist\backend-v0.4.0\start.ps1
```

管理网页为 `http://localhost:8000/#/user/login`，API 为 `http://127.0.0.1:18080`。若旧后台占用端口，先使用旧启动器输出的停止命令关闭该次运行，然后启动新版。此方式直接运行打包产物，不会反复执行 Maven 测试。

桌面安装包位于项目 `dist/desktop-v0.4.0`。为节省 E 盘空间，该目录联接到 `D:\BuildCache\pingche\release-0.4.0\desktop`，源代码、启动脚本和本机后台包保留在项目目录。退出旧桌面后自行运行 `Codex Quota Guard_0.4.0_x64-setup.exe`；安装时按系统提示授权安装统计服务。连接本机测试后台填写 `http://127.0.0.1:18080`。

旧后台不提供 USD 账本字段，不能与 0.4.0 桌面配套使用。升级前保留数据库、原 `.env` 和密钥备份，同时更新后端和管理网页，再使用新版桌面；勿清空统计服务队列或重新初始化数据库。
