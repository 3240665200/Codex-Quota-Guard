# 服务器 0.3.31：Google Authenticator 导入与验证码查看

手机已配置 GPT 验证器的管理员，可以在 Google Authenticator 中导出单个账户，在“官方账户 → 账户管理 → 验证器”中点击“导入二维码图片”。二维码仅在浏览器本地识别，保存时将标准 TOTP 密钥提交中央后台并沿用账户绑定加密保存，无需重新绑定官方账户。

- 支持单账户、单批次的 Google `otpauth-migration://offline` 二维码或链接，以及原始标准 `otpauth://totp` 配置二维码。
- 识别后显示账户标签供管理员确认，明确点击保存后生效。图片不上传，不调用第三方二维码服务。
- 保存后可点击“获取当前验证码”，与手机在同一时刻对照。该接口仅活动管理员可用，不需要管理员加入团队，也不会自动启用成员访问。
- 验证码按服务器时间生成；页面只在本次操作中显示，到期或离开窗口时隐藏，关闭后丢弃尚未返回的结果。成员仍通过桌面客户端现有登录辅助入口获取。
- 导出必须仅勾选当前 GPT 账户；拒绝多账户、分批、HOTP、MD5 和无法确定的算法配置。

本次无数据库迁移，保留所有现有账户、限制策略、统计服务授权和加密密钥。需一起更新后端和管理网页镜像：

- `minjm/codex-quota-guard-backend:0.3.31`
- `minjm/codex-quota-guard-web:0.3.31`

兼容桌面客户端 0.3.29、独立统计服务 0.2.7，无需重新安装桌面软件。真实账户二维码由管理员自行导入；自动测试仅使用 RFC 6238 公开示例密钥。

操作步骤及格式依据见[官方账户管理说明](../official-account-management.md#google-authenticator-登录验证码)。
