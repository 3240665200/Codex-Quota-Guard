# v0.3.28：额度留空即无限制，修复成员用量布局

**桌面已知问题：**未设置 7 天上限时，客户端可能误报“数据格式不完整”。请使用 [0.3.29 桌面修复版](./v0.3.29.md)；服务器 0.3.28 继续适用。

桌面客户端与服务器均为 **0.3.28**，独立统计程序保持 **0.2.7**。

## 额度规则

- 个人和团队的 5 小时、7 天上限留空均表示无限制，不继承或生成其他窗口的限额。修复未设置 7 天上限时被错误标记为不可用的问题。
- 明确填写 `0` 仍表示该窗口没有可用额度；其他已设置的个人、团队和累计上限独立生效。
- 无限制窗口仍记录真实用量。成员的“团队用量占比”是成员已用 Token ÷ 团队已用 Token，不是额度使用率。
- 管理后台的空上限和剩余额度显示“无限制”，7 天上限输入说明同步修正。

## 桌面布局

- 修复隐藏表格说明撑大整页、导致额外滚动和窗口底部空白的问题。
- 成员用量在窄窗口自动换行排列，保留每人进度条，取消表格内部的独立滚动区。
- 继续支持“剩余 / 已用”显示设置，并保留表格无障碍语义。
- 包含 0.3.27 的 HTTP/HTTPS 登录安全策略修复。

## 升级

关闭旧客户端后安装 Windows x64 安装包。安装包包含独立 Rust 统计服务及离线 WebView2 运行时，不包含 Java 或本地业务后端；统计服务由 Windows 管理，完全退出客户端后仍可上报。

服务器后端和管理网页镜像同时升级到 `0.3.28`，源码和部署配置标签为 `server-v0.3.28`。从 `0.3.25` 升级不新增数据库迁移，沿用现有 `.env`、密钥和数据卷，无需重设额度或删除用量记录。

## 验证

- 后端额度和团队成员用量集成测试 21 项通过，覆盖未设置限额、真实用量累加、明确设置为零以及各上限独立生效。
- 桌面完整单元测试 259 项、打包回归测试 13 项通过；管理网页额度、团队及显示设置相关的 22 项测试通过。
- 实际浏览器检查 375、768、900、1135、1440 宽度，以及 125% / 150% 像素密度和深浅主题，未出现整页额外滚动、横向溢出或指标截断。
