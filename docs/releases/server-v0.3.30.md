# 服务器 0.3.30：限制管理

后台新增独立菜单 **限制管理**：

- 个人额度用尽下线：每 30 秒核对个人 5 小时/7 天已设置的 Token 上限，达到后撤销该用户精确绑定的官方会话。未设置上限仍为无限制。
- 未绑定会话清理：默认每 90 分钟检查，跳过官方标记的当前设备、受信任设备、有效绑定及状态不明的目标。
- 两条规则分别启停，提供账户最近/下次检查时间、执行记录和不确定结果提示。

所有任务由中央服务器持续执行。规则及时间持久保存，发送前重新核对绑定、额度和设备；多实例使用数据库互斥，官方限流冷却跨重启生效，未知结果不会自动重复下线。

新规则初始关闭，在“限制管理”中保存启用后生效。升级新增 **V37**；保留原环境配置、密钥和数据库卷，更新后端与网页两项镜像。
