# Codex Quota Guard v0.3.0

本版本重做桌面客户端配色与工作区布局，并包含 v0.2.20 之后的流水展示优化。

## 更新内容

- 与管理后台统一暖白、深灰和青绿色配色，支持浅色、深色、跟随系统，并保存外观偏好。
- 采用可收起的侧栏导航，将额度总览、用量统计、消耗流水、统计程序拆分为独立页面。
- 个人 Token、团队共享额度和官方 Codex 参考额度分区展示，保留进度条和精确数值提示。
- 流水采用精简列表，详情弹窗保留输入、输出、缓存、思考 Token、模型、思考等级、时间与 USD 费用估算。
- 优化窄窗口、图标对齐和深色图表显示，提高浅色文字对比度。
- 统一统计程序异常提示；状态读取失败时明确区分失败、加载中和上次读取结果。
- 将 CC Switch 冲突守卫的简短风险提示固定在工作区顶部，详细说明可展开，不随流水或日志滚走。
- 包含管理后台侧栏对齐及概览流水完整时间显示修复。

## 安装与升级

- 下载 `Codex.Quota.Guard_0.3.0_x64-setup.exe`，适用于 Windows x64。
- 安装包内含 Java 17、WebView2 离线安装程序及 Rust 统计程序，无需自行安装开发环境。
- 从系统托盘退出旧客户端后再安装新版。安装完成后仍需以管理员身份运行客户端。
- 中央 Java 服务和管理后台不包含在桌面安装包中，需单独运行；本次桌面改版无需数据库迁移。
- Rust 统计程序版本保持 `0.2.1`，本次没有修改其采集逻辑。
- 安装包未进行代码签名，Windows 可能显示未知发布者提示。

## 保留的行为与限制

- Windows 启动检查、系统账户登录及 CC Switch 冲突守卫保持不变。运行客户端期间会强制结束同一 Windows 用户会话中识别到的 CC Switch，未保存内容可能丢失；关闭到托盘仍视为运行。
- 冲突守卫并不具备不可绕过的防篡改能力，也不能替代官方账户 ID 归属校验；结束 CC Switch 后不会自动恢复其修改过的代理配置。
- 官方账户额度与系统个人 Token 限额是两种不同口径；USD 金额是按配置价格计算的估算值，不是官方账单。
- 本次未在全新 Windows 机器执行安装或启动真实统计服务；发布前执行本地自动化测试、构建及资源完整性检查。仓库当前没有配置 GitHub Actions CI。
- 浏览器界面预览使用独立演示数据，预览入口和数据不包含在生产构建中。

校验文件 `SHA256SUMS.txt` 与安装包同时发布。
